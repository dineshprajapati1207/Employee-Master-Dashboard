1. Employee information files

Both .xls and .xlsx files are accepted. Filename must be the Emp Code (e.g. 0001.xlsx, 1001.xls). Select many files at once. A new code is added; an existing code is replaced with the latest file. Nothing else is touched.

Click to choose or drag & drop employee files here

2. Master Sheet template

Your template is saved here, so you never need to upload it again. Upload a file only when the template changes; the new one then replaces it for all future exports. Sheet names, headings, column order and styling are kept exactly.

Sheets: Active, Dependant Details, Experience. Missing details stay blank; nothing is guessed.
